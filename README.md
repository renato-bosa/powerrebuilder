# SIME Finch

PowerBuilder reverse engineering toolkit that converts legacy PowerBuilder applications into modern web applications.

## Installation

```bash
uv sync
```

## Usage

```bash
uv run sime-finch --help
```

## Development

```bash
# Install with dev dependencies
uv sync --dev

# Run tests
uv run pytest

# Run linting
uv run ruff check .

# Format code
uv run ruff format .
```
