# Pre-Refactor Backup Files

This directory contains backup files from before the major refactoring of the PowerRebuilder codebase. These files were preserved for historical reference.

## Files

### exceptions.py.backup
- **Original location**: `src/common/exceptions.py`
- **Description**: Previous implementation of the common exceptions module before consolidation

### interfaces.py.backup (from src/extract/)
- **Original location**: `src/extract/interfaces.py`
- **Description**: Extract module interfaces before the refactoring

### interfaces.py.backup (from src/parse/)
- **Original location**: `src/parse/interfaces.py`
- **Description**: Parse module interfaces containing protocols for type parsers and related structures

## Purpose

These backup files were created during the refactoring process to preserve the original implementations. They can be referenced if needed to understand the evolution of the codebase or to recover any functionality that may have been inadvertently lost during the refactoring.

## Note

These files are no longer part of the active codebase and should not be imported or used in production code. They are retained purely for historical reference.
